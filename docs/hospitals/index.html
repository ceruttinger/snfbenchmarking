Data & definitions

What these comparisons mean

Source and report selection

CMS Hospital Provider Cost Report records for 2017–2024 are retrieved through paginated JSON API queries. Raw CSV and ZIP distributions are not downloaded. The page loads a compact derived cache for fast static hosting. The source contains selected HCRIS measures, not every worksheet field. Where multiple reports exist for a CCN in a source dataset, the pilot prefers a 300–430-day report, then longest duration, latest end date and highest report ID. It does not add partial reports together.

· Data manifest and selection counts

Scopes, missing values and peer groups

Cost-report totals can include hospital-complex components. The initial peer group matches the target’s CCN category, clinical provider type and bed-size band. Users can redefine geography, category, ownership, clinical type, rural status, bed bands and minimum/maximum beds, or exclude individual peers; comparisons are descriptive and are not adjusted for case mix, teaching or local wage levels. Missing inputs and nonpositive denominators produce unavailable metrics. Occupancy outside 0–100% is excluded. No missing amount is treated as zero. Extreme remaining values are retained, with robust peer medians.

Bed bands: under 25, 25–99, 100–299, and 300+. Short or unusually long selected reports can be inspected but receive no peer percentile. Peer groups below five facilities are labeled too small for benchmarking. Percentiles use a midpoint rank for ties.

Metric definitions and RAND distinction

Patient-service margin is distinct from RAND operating margin. Total margin follows RAND’s documented net-income / (net-patient-revenue + other-income) formula using CMS fields. RAND’s exclusions for operating margin, CMI adjustments, prices and other supplemental measures cannot be reconstructed from this subset without further inputs.

Source: Centers for Medicare & Medicaid Services. Independent derived analysis; not affiliated with CMS or RAND. This pilot measures reported economics, not clinical quality.
